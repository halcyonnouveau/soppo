# Examples

| Example | Description |
|---------|-------------|
| `guessing_game.sop` | Number guessing game with user input |
| `todo_cli.sop` | Interactive todo list with enums |
| `file_processor.sop` | Read and process text files |
| `http_server.sop` | Simple HTTP server |

For larger projects written in Soppo:

- [SOPMOD](https://github.com/halcyonnouveau/sopmod) - Version manager for Soppo
- [Slap](https://github.com/beanpuppy/slap) - Clap-style CLI parser
- Soappo (TODO) - HTTP server framework
